---
title: Compare two files
summary: Put two documents side by side, or compare a file with one of its earlier versions.
---

Kaelio can show two files next to each other, and can show any file beside an earlier version of itself.

## When to use it

- When you have two drafts and want to see how they differ.
- When you want to check what changed in a note since yesterday.

## How to use it

### Two different files

1. In the Explorer, right-click the first file and choose **Select for Compare**.
2. Right-click the second file and choose **Compare with Selected**.
3. The first opens on the left, the second on the right. Use **Toggle Sub Pane Edit / Preview** to compare formatted pages instead of source.

### A file and its earlier version

1. Right-click the file and choose **File History**.
2. On **Commits** (if the folder uses Git) or **Snapshots**, click **View** beside a version.
3. The old version appears beside the current one as **Selected version** and **Current**.
4. Click **Restore this version** to take the old text into the editor, or **← Back** to look at another.

## What it will not do

- Kaelio does not highlight changed lines; you compare by reading side by side.
- Viewing an old version never changes your file.
