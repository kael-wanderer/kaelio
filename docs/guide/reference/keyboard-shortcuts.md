---
title: Keyboard shortcuts
summary: Every default shortcut, and how to change them in Customize Shortcuts.
---

Press <kbd>⌘</kbd><kbd>/</kbd> at any time to see the shortcuts in Kaelio itself. The list there always shows your own keys if you changed any.

## When to use it

- When you want to work without the mouse.
- When a shortcut clashes with another app and you want to change it.

## How to use it

### Default shortcuts

**File**

| Action | Keys |
|---|---|
| New File | <kbd>⌘</kbd><kbd>N</kbd> |
| Open File | <kbd>⌘</kbd><kbd>O</kbd> |
| Save | <kbd>⌘</kbd><kbd>S</kbd> |
| Close Tab | <kbd>⌘</kbd><kbd>W</kbd> |
| New Window | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>N</kbd> |

**View**

| Action | Keys |
|---|---|
| Show/Hide Preview | <kbd>⌘</kbd><kbd>⌥</kbd><kbd>P</kbd> |
| Reading View | <kbd>⌘</kbd><kbd>E</kbd> |
| Toggle Outline | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>O</kbd> |
| Show/Hide Explorer | <kbd>⌘</kbd><kbd>B</kbd> |
| Zoom In | <kbd>⌘</kbd><kbd>=</kbd> |
| Zoom Out | <kbd>⌘</kbd><kbd>-</kbd> |
| Reset Zoom | <kbd>⌘</kbd><kbd>0</kbd> |

**Edit**

| Action | Keys |
|---|---|
| Copy Formatted | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>C</kbd> |
| Paste as Plain Text | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>V</kbd> |
| Undo / Redo | <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⌘</kbd><kbd>⇧</kbd><kbd>Z</kbd> |
| Indent / Outdent | <kbd>Tab</kbd> / <kbd>⇧</kbd><kbd>Tab</kbd> |

**Search**

| Action | Keys |
|---|---|
| Command Palette | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd> |
| File Search | <kbd>⌘</kbd><kbd>P</kbd> |
| Search in Files | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>F</kbd> |
| Find (and replace) in file | <kbd>⌘</kbd><kbd>F</kbd> |

**Help**

| Action | Keys |
|---|---|
| Keyboard Shortcuts | <kbd>⌘</kbd><kbd>/</kbd> |

On Windows and Linux, use <kbd>Ctrl</kbd> where these list <kbd>⌘</kbd>.

### Change a shortcut

1. Choose Help ▸ **Customize Shortcuts**.
2. Click **Edit** beside an action. The key reads **Press shortcut...**.
3. Press the new keys. <kbd>Esc</kbd> cancels; <kbd>Delete</kbd> removes the shortcut (**Unbound**).
4. If the keys already belong to another action, Kaelio says which one. Press <kbd>Return</kbd> to swap the two, or <kbd>Esc</kbd> to keep things as they were.

**Reset All** puts every shortcut back to its default. Keys macOS reserves, such as <kbd>⌘</kbd><kbd>Q</kbd>, are marked **(system shortcut!)**: you can still choose them, but macOS may take them first. Find, Undo/Redo and Indent/Outdent cannot be changed.

## What it will not do

- Your shortcuts stay on this computer; they are not copied to other computers.
