The fastest way to learn Kaelio is to open a folder of notes and write one. This page takes about five minutes.

## When to use it

- Right after installing Kaelio.

## How to use it

### 1. Open a folder

Choose File ▸ **Open Folder...** and pick a folder, for example a `Notes` folder in Documents. Its files appear in the **Explorer** on the left. Kaelio remembers the folder and opens it again next time.

You can also drag a folder from Finder onto the Kaelio window.

### 2. Make a note

Press <kbd>⌘</kbd><kbd>N</kbd>. Kaelio creates `untitled.md` in the folder and opens it. To choose a name instead, click **+** (**New File**) at the top of the Explorer.

Type something with a little Markdown:

```markdown
# Shopping

- [ ] Coffee
- [x] Bread

> [!tip] Remember
> The market closes at six.
```

The preview on the right updates as you type: a heading, a checklist and a tip box. Click a checkbox in the preview to tick it.

### 3. Save

Press <kbd>⌘</kbd><kbd>S</kbd>. The **●** beside the file name disappears. If you would rather never think about saving, run **Toggle Auto-save** from the Command Palette (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd>).

### 4. Read

Press <kbd>⌘</kbd><kbd>E</kbd> for **Reading View**: the editor hides and the preview fills the window. Press <kbd>⌘</kbd><kbd>E</kbd> again to come back. <kbd>⌘</kbd><kbd>P</kbd> hides or shows the preview instead.

### 5. Make it yours

Click the gear at the bottom left (**Appearance Settings**) to choose a theme, font and text size.

## What it will not do

- Kaelio does not copy your folder anywhere. The files you see are the files on your disk, and other apps can open them as usual.
