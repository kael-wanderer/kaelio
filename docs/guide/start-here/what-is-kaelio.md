Kaelio is a Markdown editor for reading and writing plain text files. You type on the left, and the preview on the right shows the formatted result as you go, including diagrams, math and callouts. There is no vault, no account and no import step: open any `.md` file or folder and start.

Kaelio runs on macOS (Apple silicon and Intel), Windows and Linux. It is free and open source under the GPL-3.0 licence.

## When to use it

- When you write notes, documentation or drafts in Markdown and want to see the result while you type.
- When you read Markdown that others wrote, such as README files or AI-generated reports, and want it nicely formatted.
- When you want your notes backed up to GitHub without learning Git.
- When you want to read a PDF beside the notes you take on it.

## How to use it

The window has a few parts. Each has its own page in this guide.

| Part | What it is for |
|---|---|
| [Editor and preview](../writing/editor-and-preview.md) | Write on the left, see the formatted page on the right, or read with the editor hidden. |
| [Explorer](../files/explorer-and-tabs.md) | The files of the folder you opened, with tabs for open files. |
| [Split view](../writing/split-view.md) | A second pane to edit or compare another file side by side. |
| [Search](../files/search.md) | Find a file by name, search inside files, or run any command from the Command Palette. |
| [Git panel](../git/git-sync.md) | Back up and sync a folder with GitHub. |
| [File History](../git/history-and-snapshots.md) | Earlier versions of a file, from Git and from automatic snapshots. |
| [Export](../export/export.md) | Save a document as PNG, JPG, PDF or DOCX, or copy it formatted. |

Kaelio also opens images, PDFs, HTML, JSON, CSV and other text files. See [Images and other files](../files/images-and-other-files.md) and [Read and highlight PDFs](../files/pdf-viewer.md).

> [!TIP]
> Press <kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd> to open the Command Palette and type what you want to do. Every command is there.

## What it will not do

- It never changes a file until you save it, or until you turn on auto-save.
- It never moves your files into a library or a special format. Your notes stay ordinary files in ordinary folders.
- It does not collect usage data. It goes online only for the few things listed in [Privacy](../reference/privacy.md).
