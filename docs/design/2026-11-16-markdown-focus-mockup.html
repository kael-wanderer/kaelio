What changed

The sync job now retries three times before it reports a failure, and each retry waits twice as long as the one before.

Retries are skipped when the server answers 401 or 403, because a new attempt cannot succeed without new credentials.

Logs keep the request id for every attempt so a failed run can be traced end to end.

The default timeout is now 30 seconds (was 10).
